## 修复内容

### Bug 1: merge conflict markers 残留

两处冲突位于鉴权白名单行，合并两边内容：

```python
# Before (两处)
<<<<<<< Updated upstream
        if request.path in ("/", "/favicon.ico", "/logo.png", "/assets/logo.png"):
=======
        if request.path in ("/", "/health", "/metrics", "/logo.png", "/assets/logo.png"):
>>>>>>> Stashed changes

# After
        if request.path in ("/", "/favicon.ico", "/health", "/metrics", "/logo.png", "/assets/logo.png"):
```

### Bug 2: get_astrbot_data_path() 返回 str

AstrBot 的 `get_astrbot_data_path()` 返回 `str`，不是 `Path`。三处使用点包裹 `Path()`：

```python
# Before
get_astrbot_data_path() / "sylanne_alpha"

# After
Path(get_astrbot_data_path()) / "sylanne_alpha"
```

涉及文件：
- `sylanne_alpha/session_context.py` line 336, 384
- `sylanne_alpha/webui_server.py` line 2061

## 根因分析

Bug 1 是 1.3.2 发布流程的失误：在 `G:\Sylanne-embodiment` 上 `git stash pop` 后产生冲突，未检查直接 commit + force push。此后已建立 `G:\Sylanne-bug` 独立工作台避免迭代代码和 hotfix 互相污染。

Bug 2 是 AstrBot API 的类型契约问题：`get_astrbot_data_path()` 文档标注返回 Path 但实际返回 str。fallback 实现返回 `Path.home()` 所以本地测试不会触发。
