# Sylanne 3.0 关系性自我诞生证据映射

> 用途：为 `3.0.0-exp` 的“关系性自我诞生 / Relational Self Genesis”提供可追溯理论依据。本文是研究规划与证据地图，不等同于实证结论。

| ID | 理论 / 来源方向 | 可用事实 | 支撑的 3.0 主张 | 风险 |
| --- | --- | --- | --- | --- |
| RSG01 | Relational self；Cross、Andersen；relational schemas | 自我表征会在特定关系中被定义、激活和维持。 | Sylanne 的长期变化可被建模为关系历史驱动的自我表征变化，而不是孤立人格参数漂移。 | 中：不能直接推出 AI 拥有真实自我。 |
| RSG02 | Dialogical self；Hermans；I-positions | 自我可由多个位置和声音构成，并在对话中重排。 | Sylanne 可维护多个关系性“我-位置”，如协作者、陪伴者、被纠正者、群聊参与者。 | 中：需要避免把工程状态说成真实内在声音。 |
| RSG03 | Narrative identity；McAdams、Ricoeur | 身份连续性来自把经历组织成叙事。 | 自我诠释引擎应把事件转成 event meaning、relational meaning、self narrative shift。 | 低-中：叙事身份用于人类研究，迁移到 AI 时必须标注为模拟。 |
| RSG04 | Autobiographical memory；Conway、Rubin；self-memory system | 自传体记忆由事件、自我知识和叙事组织共同支撑。 | 转折点记忆不能只是事实记录，应包含意义、关系后果和后续影响。 | 中：需要区分记忆检索与身份功能。 |
| RSG05 | Distributed cognition；Hutchins、Salomon | 认知可以分布在人、工具、表征和互动流程中。 | Sylanne 3.0 可被理解为用户、agent、记忆库、状态引擎和 WebUI 观察舱共同构成的模拟研究系统。 | 中：不能把分布系统直接说成单一主体。 |
| RSG06 | Attachment and co-regulation；Bowlby、Ainsworth、Tronick、Feldman | 稳定关系通过反复回应、节律同步、修复和共调节形成。 | 关系时间层应追踪互动节律、等待、修复、依赖、沉默和共同典故如何塑造关系空气。 | 高：依恋术语容易被过度拟人化，需谨慎使用。 |
| RSG07 | Human-AI relationship；Reeves & Nass、Turkle、Darling；ELIZA effect | 用户会对计算系统产生社会反应和陪伴期待，但体验不等于系统真实理解。 | 3.0 可以研究人机长期关系现象，同时必须保留反拟人化边界。 | 高：最容易被误读为宣传 AI 有真实情感。 |
| RSG08 | Generative Agents；Park et al. 2023 | 记忆、反思、计划可增强 believable agent behavior。 | Sylanne 3.0 可在 2.x 记忆/反思基础上推进到关系事件解释、回放和分叉。 | 中：不能把 believable behavior 等同于真实主体性。 |
| RSG09 | Appraisal theory；OCC、Lazarus、Scherer、Roseman | 事件意义取决于目标、控制、责任、规范和关系语境。 | 自我诠释引擎应先解释“这件事对我/我们意味着什么”，再产生后续倾向。 | 低：现有 Sylanne 理论已使用，需扩展到关系性意义。 |
| RSG10 | Conversation analysis and grounding；Sacks、Schegloff、Jefferson、Clark & Brennan | 对话依赖 turn-taking、共同语境和 grounding。 | 关系时间层应追踪共同典故、未尽主题、协作习惯和对话节律。 | 低：适合工程化。 |
| RSG11 | Relationship repair；McCullough、Fehr、Lewicki、Ohbuchi | 修复依赖责任、伤害承认、补偿、未来承诺和重复模式。 | 转折点记忆应把误解、纠正和修复作为可能改变关系自我解释的事件。 | 低-中：需避免把所有冲突都过度解释。 |
| RSG12 | Personality as state distribution；Fleeson；CAPS/Mischel & Shoda | 人格可表现为跨情境状态分布和 if-then 模式。 | 3.0 可允许同一 Sylanne 在不同关系历史下自然分叉，而不是追求单一稳定人格。 | 中：需要与现有 bounded drift 设计协调，强调研究观察而非压制。 |
| RSG13 | Memory theory；Tulving、Ebbinghaus、Bjork、Schacter、Anderson | 记忆有情景/语义层次、遗忘、检索线索和重建性。 | 关系性 recall 应区分事件事实、语义偏好、转折点意义和当前关系空气。 | 低：已被 2.x 使用，可扩展。 |
| RSG14 | Computational narrative / narrative planning | 事件、目标、角色、因果和时间结构可被计算组织为故事。 | 谱系与分叉可以把关系历史表示为可 replay 的叙事轨迹，而非流水账。 | 中：需要查证更具体文献。 |
| RSG15 | Memory-augmented LLM agents / persona consistency | 长期 agent 通过记忆、reflection、persona consistency 维持跨轮行为。 | Sylanne 3.0 的 novelty 应从 persona consistency 进一步推进到 self-interpretation 和 relational branching。 | 中：需网络文献补齐最新工作。 |

## 后续查证优先级

1. **先查 relational self + narrative identity**：直接支撑“关系中生成自我”。
2. **再查 dialogical self + autobiographical memory**：支撑“自我诠释”和“转折点”。
3. **再查 distributed cognition + human-AI relationship**：支撑“共演化”和“人机长期互动”。
4. **最后查 memory-augmented agents + computational narrative identity**：把心理学理论落到 agent 架构。

## 禁止直接得出的结论

- 不能从 RSG01-RSG07 推出 Sylanne 有真实意识。
- 不能从用户依恋感推出 Sylanne 有真实依恋。
- 不能从长期一致性推出真实主体性。
- 不能从 narrative identity 类比推出 AI 具有人类式生命故事。
- 不能把“关系性自我诞生”写成临床、哲学或本体论结论。
