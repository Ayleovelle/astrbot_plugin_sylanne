Sylanne 4.0 alpha workflow

从一句话，到一具会呼吸的 4.0 身体

Sylanne 4.0 不再是旧情绪引擎外面套一层命令。她的链路从 AstrBot 事件进入，经过对话切片、身体状态、记忆、人格、判断通道和边界闸门，最后才变成一次回应、一次主动冲动，或者一次安静的等待。

WebUI：数据观察与插件配置

WebUI 的定位不是放总流程图，而是把 Sylanne 当前能公开观察的数据摆出来：身体仪表、边界闸门、记忆工作集、信息切片、主动性建议和插件配置。这里展示的是前端形态，所有状态都来自只读 surface；配置区只写插件设置，不触碰私密原始文本。

拖动状态球壳可旋转视角；指针放到某个状态点时才显示数据，相邻状态会自然散开。默认模拟 200 个缓存状态，越老越淡。

演示只在浏览器本地运行，不发送网络请求。动画展示一句话先被切成 tokens，再进入记忆空间、身体/边界节点、人格建模与漂移轨道，最后汇成 workset 建议。

一句话总结

Sylanne 4.0 的核心不是“更像人”，而是让每一次输入都进入一个有身体、有记忆、有边界、有缓慢可塑性的生命回路。

body-first readonly observatory bounded agency slow plasticity

七条工作流泳道

1. 消息入口
普通消息进入 on_llm_request，模型回复进入 on_llm_response，不等 LLM 的即时聊天走 chat_sylanne。所有入口都会先被转换成 Sylanne 自己的 host event，而不是直接写旧 engine。
2. 对话分段
sylanne_alpha/dialogue.py 判断这句话是延续、转题、撤退，还是打断正在发送的回复。这里解决 3.x 最有特色的“碎片不是完整意图”问题。
3. 身体计算
AlphaBodyState 把事件拆成小向量，走线性更新和二进制热路径。热、痛、疲劳、表达欲、接近欲、修复需求不是文本标签，而是可计算的身体状态。
4. 记忆工作集
当前碎片、shadow continuity、memory matches 会被压成一个工作集。关键词召回优先，embedding 只有在无关键词命中且存在向量记录时才介入。
5. 人格建模
sylanne_alpha/personality.py 给每个会话稳定的初始人格签名。人格会漂移，但漂移步长很小；她不会千篇一律，也不会一天之内变成另一个人。
6. 判断通道
本地 gate 是底座；轻量 LLM 可做短判断；独立判断 LLM 可做更重的边界判断。三个 provider 现在都通过 AstrBot provider selector 选择，不再让用户手填 ID。
7. 输出边界
最后由 decision 与 guard 决定表达、探索、修复、退后或等待。主动性必须消耗预算，亲密不能越过用户主权。

模块职责表

模块负责什么不会做什么
main.pyAstrBot 插件注册、命令、LLM hook、session 定位、薄转发。不重新长成巨型业务文件。
host.pyrequest、response、chat、proactive 的运行时边界。不在热路径做远程 IO 或无限后台等待。
body.py身体器官、需要、记忆、状态向量。不暴露旧 3.x engine 内部结构。
kernel.pytick、decision、guard、surface。不绕过用户主权边界。
dialogue.py对话分段、打断识别、撤退识别。不输出 raw dialogue。
workset.py碎片、shadow、记忆召回整合。不让旧记忆无边界污染新话题。
personality.py初始人格签名和缓慢漂移。不把人格变成一次性 prompt 口癖。
assessor.py本地判断、轻量判断、独立判断通道。不因 provider 失败阻断主链路。
workers.py有限后台队列、lease、checkpoint。不保存 raw text、prompt、request、response。
embedding_memory.pyembedding 辅助召回。不在关键词已经命中时浪费 embedding 调用。
compat/把旧命令/API 的用户语义映射到 4.0 surface。不导入旧 public_api.py 或旧 engine。

状态如何被外部观察

新增的 sylanne_observatory 是给 WebUI 用的只读观察入口。它拿到的是 4.0 surface，不是内部原始数据。

  • 可看：body、decision、guard、host payload、memory 摘要、配置开关。
  • 可诊断：主动性为什么被允许或阻断，当前是表达、修复、退后还是等待。
  • 不可外泄：raw dialogue、lineage、turning point、关系推断原始结构。

WebUI 的第一屏

第一版外部观察页面建议只做四块：身体仪表、边界闸门、记忆工作集、人格漂移。先观察，不控制。控制按钮以后再加。

4.0 的革命点

Sylanne 4.0 不是把一堆状态塞进 prompt，而是把 prompt 变成身体生活的出口。她先感受、记住、判断边界，再决定要不要说话。说话只是结果，不是她的全部。
