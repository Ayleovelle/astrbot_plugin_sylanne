# 明日方舟（Arknights）UI 设计语言完整参考

> 鹰角网络（Hypergryph）| 创始人/艺术总监：海猫（Lowlight）
> 核心定位：**军事工业科幻 × 制药公司终端 × 极简主义**

---

## 一、设计哲学

明日方舟的 UI 不是"游戏菜单"，而是**罗德岛移动医疗平台的作战指挥终端**。每一次交互都在强化这个叙事前提。

核心原则：
- **世界观即界面**：UI 本身是叙事的一部分，不是覆盖在游戏上的外壳
- **极简但不空洞**：每个元素都有功能意义，拒绝纯装饰
- **克制的信息密度**：渐进式披露（Progressive Disclosure），不在第一眼展示所有信息
- **工业精密感**：一切运动都是"有目的的"、"被控制的"、"有重量的"

与同类游戏的根本区别：在其他 gacha 游戏追求花哨热闹时，方舟选择了冷峻与克制。

## 二、色彩体系

### 2.1 主色调

| 角色 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#1B1B1B` ~ `#2B2B2B` | 近黑深灰，非纯黑 |
| 次级背景/面板 | `#313131` ~ `#3C3C3C` | 卡片/面板底色 |
| 浅色面板 | `#FDFDFB` | 信息载体，浮于暗底之上 |
| 主文字色 | `#FFFFFF` ~ `#FFF9EF` | 暖白，非纯白，减少视觉疲劳 |
| 次要文字 | `#989898` | 描述/辅助信息 |
| 深色文字（亮底上） | `#323232` ~ `#333333` | 面板内正文 |

### 2.2 强调色

| 用途 | 色值 | 说明 |
|------|------|------|
| 品牌标记线 | `#FF5E19` | 面板顶部橙红短横线——最具辨识度的设计元素 |
| 科技蓝/选中态 | `#0098DC` ~ `#00B0FF` | 功能区块、链接、高亮 |
| 功能区块蓝 | `#05A7DC` | 商店/招募类入口 |
| 警告/危险 | `#FF6237` ~ `#F44336` | 错误、敌方标识 |
| 理智/体力 | `#00BFFF` | 亮蓝 |

| 星级 | 色值 | 视觉处理 |
|------|------|----------|

| 5★ | `#FFD800` ~ `#FFC107` | 金黄，微光粒子 |
| 4★ | `#D1B3FF` ~ `#C8A8FF` | 薰衣草紫 |
| 3★ | `#00B2FF` ~ `#2196F3` | 蓝色 |
| 2★ | `#DCE775` ~ `#D4E157` | 黄绿 |
| 1★ | `#BDBDBD` ~ `#9E9E9E` | 灰色 |

### 2.4 材料等级背景色

| 等级 | 背景色 |
|------|--------|
| T1 基础 | 灰/白 |
| T2 初级 | 绿色 |
| T3 中级 | 蓝色 |
| T4 高级 | 紫色 |
| T5 顶级 | 金/橙 |

### 2.5 色彩策略

- **低饱和度背景 + 高饱和度焦点**：营造"暗室中的终端屏幕"感
- 颜色几乎只用于**功能区分**（稀有度、职业、状态），而非装饰
- CSS 变量使用 RGB 三元组：`rgb(var(--highlight-primary-color), 0.8)` 灵活控制透明度
- 高亮色可随活动/主题动态切换

## 三、字体系统

### 3.1 字体家族

| 用途 | 字体 | 特征 |
|------|------|------|
| UI 数值/编号 | **Bender** | 几何工业风无衬线，方正硬朗 |
| 英文标题 | **Novecento Wide** | 宽体无衬线，全大写设计 |
| 中文正文 | **Noto Sans SC / 思源黑体** | 500/700/900 三字重 |
| 中文功能标题 | **Noto Serif SC / 思源宋体** | 增加仪式感 |
| 等宽/数据 | **JetBrains Mono** | 代码/数据显示 |
| 定制主字体 | **Zuijin** (自研) | wikidot 主题默认 |
| 装饰性标题 | **Cinzel / Cinzel Decorative** | 特定场景衬线体 |
| RI Logo | **Trajan Pro Bold** | 古典碑文风格 |

### 3.2 字体层级

```
功能名称（编队/干员）：Noto Serif SC, 900, ~40px
数值/编号：          Bender, 700, ~33px
正文/描述：          Noto Sans SC, 500, ~14-16px (1rem)
标签/辅助：          Noto Sans SC, 400, ~12px (0.85rem)
```

### 3.3 排版规则

- 标题用**宋体/衬线体**增加仪式感，正文用**黑体/无衬线**保证可读性
- 数字始终使用 Bender，与中文正文形成视觉对比
- 文字阴影极少使用，仅在复杂背景上：`text-shadow: #8b8b8b 5px 5px 0px`

## 四、UI 组件

### 4.1 按钮

**核心特征：绝对直角，无圆角，无投影，色块即按钮。**

**功能区块按钮（主导航）：**
```
┌─────────────────────┐
│  [半透明图标]        │  ← 右侧/右下角, opacity: 0.5
│  大号宋体标题        │  ← 左上角, Noto Serif SC, 900
│  小号描述文字        │  ← 标题下方, #989898
└─────────────────────┘
```

色彩区分功能类型：
- 白色底 `#FFF`：编队、任务（主要操作）
- 浅灰底 `#EBECEB`：干员管理、基建（次要操作）
- 深灰底 `#424242`：仓库、好友（辅助功能）
- 青蓝底 `#05A7DC`：商店、招募（消费/获取类）

交互状态：
- 按下：scale 0.95~0.98 + 亮度微降
- 释放：快速回弹 + 短促"咔嗒"音效
- 禁用：opacity 0.4，去除所有反馈

### 4.2 面板/卡片

- **直角矩形**，border-radius: 0
- **无 box-shadow**，依靠色块对比区分层级
- **半透明**：opacity 0.7~0.9
- **顶部橙红标记线**：`#FF5E19`，高 6px，宽 180~310px——品牌标识性元素

分隔线：渐变边框，两端淡出
```css
border-image: linear-gradient(#05a7dc, #454545, #05a7dc) 1;
```

### 4.3 斜切角矩形

大量使用 **chamfered rectangle**——矩形四角被 45° 切割。这是方舟区别于普通直角矩形的标志性形状语言。

### 4.4 角饰与装饰

- **L 形直角标记**：类似技术图纸定位标记
- **菱形装饰点**：分割线中央
- **网格线/六边形蜂巢**：背景纹理
- **斜线阴影（hatching）**：区域标识
- **极淡电路板线条**：面板背景

### 4.5 进度条

- 细长矩形，无圆角
- 填充色：橙红 `#FF5E19`（理智）/ 绿色（HP）/ 蓝色（SP）
- 底部灰色轨道 + 彩色填充
- 数值以分数形式显示：`125/125`

### 4.6 弹窗/对话框

- 半透明黑色遮罩：`rgba(0, 0, 0, 0.5)`
- 居中面板，直角矩形
- 从中心 scale 0.9→1.0 展开
- 按钮组：左"取消"（灰/空心）+ 右"确认"（实色填充）

## 五、布局与信息架构

### 5.1 主界面结构

```
┌──────────────────────────────────────────────────────┐
│ [头像+等级]                         [时间] [资源栏]   │  ← 顶部状态栏
│                                                        │
│                                                        │
│              [角色立绘 - 占 60-70% 面积]               │  ← 中央视觉焦点
│                                                        │
│ [语音框]                        [理智/体力面板]        │
│ [活动Banner]                    [编队][干员][■]        │  ← 功能矩阵
│ [好友][情报]                    [商店][招募]           │
│                                 [任务][基建][仓库]     │
└──────────────────────────────────────────────────────┘
```

关键特征：
- **无底部 Tab Bar**——与传统手游完全不同
- **左右分区**：左侧社交/信息，右侧核心功能矩阵
- **透视倾斜**：左右菜单有 3D perspective 效果
  ```css
  transform: perspective(30em) rotateY(10deg) scale(0.9);   /* 左侧 */
  transform: perspective(30em) rotateY(-10deg) scale(0.9);  /* 右侧 */
  ```
- **纯横屏**，消除竖屏适配复杂性

### 5.2 信息三级递进

| 层级 | 内容 | 交互深度 |
|------|------|----------|
| 第一层 | 资源数值、导航入口、状态红点 | 即时可见 |
| 第二层 | 稀有度/职业/等级、推荐等级、产出状态 | 一次交互 |
| 第三层 | 详细数值、技能公式、档案文本、模组效果 | 深层探索 |

### 5.3 干员详情页——数据密集界面处理

```
┌────────────────────────────────────────┐
│ [干员立绘 ~40%]  │  [数据面板 ~60%]    │
│                  │  ┌─────────────────┐ │
│                  │  │ 属性│技能│天赋│… │ │  ← 标签页分层
│                  │  │                 │ │
│  （固定锚点）    │  │  （可切换内容） │ │
│                  │  └─────────────────┘ │
└────────────────────────────────────────┘
```

数据密集界面策略：
- 数值 + 进度条**双通道**呈现
- 技能等级**滑块**查看不同等级数值
- 颜色编码区分技能类型（自动回复/攻击回复/被动）

### 5.4 基建（RIIC）

- **等轴测视角**展示基地全貌
- 21 房间 + 走廊/电梯共 45 空间
- 点击进入 **Master-Detail** 模式

### 5.5 间距系统

- 基础单位：~8px
- 按钮触控高度：44-48dp
- 卡片间距：8-12px
- 屏幕安全边距：16-24px
- 面板间 margin：8-16px
- 面板内 padding：10-15px

## 六、Z 轴层叠与深度

### 层级结构（底→顶）：

1. **背景层**：全屏背景图/动态背景
2. **角色层**：干员立绘，带视差效果
3. **UI 框架层**：顶部栏、底部导航、侧边功能区
4. **面板层**：信息面板（60-80% 不透明度深色底板）
5. **弹窗层**：确认对话框、奖励展示
6. **全屏覆盖层**：加载画面、过场动画

### 深度表现手法：

- **半透明叠加**：面板 opacity 0.7~0.9，透出背景层
- **模糊效果**：弹窗出现时背景轻微 blur
- **极少使用投影**：依赖明度差异区分层级
- **视差滚动**：背景与前景不同速度移动
  ```javascript
  data-depth="0.0"   // 背景层
  data-depth="0.01"  // 角色层
  data-depth="0.2"   // UI 层
  ```

## 七、动效与运动设计

### 7.1 整体手感

**"冷静、精密、有控制力的紧张感"**

- 不是"轻快弹跳"——没有过度弹性动画
- 不是"缓慢优雅"——动画干脆不拖泥带水
- 是"机械精密"——每个动画像精密仪器运作
- 是"暗流涌动"——表面克制，粒子/呼吸灯暗示不安

### 7.2 转场动画

| 类型 | 描述 | 时长 |
|------|------|------|
| 斜向滑入 | 最具标志性，面板从对角线方向滑入 + 斜线切割引导 | 250-400ms |
| 淡入+位移 | Y轴 10-20px 向上 + opacity 0→1，元素间 stagger 50-80ms | 200-300ms |
| 遮罩切割 | 斜线矩形遮罩从一侧"擦除"旧界面 | 300-400ms |
| 缩放+淡入 | 弹窗从 scale 0.95 放大到 1.0 | 200-300ms |

### 7.3 缓动曲线

| 场景 | 曲线 | 近似值 |
|------|------|--------|
| 元素入场 | ease-out（减速落定） | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 位置切换 | ease-in-out | `cubic-bezier(0.42, 0, 0.58, 1)` |
| 弹窗/面板 | 快出慢入 | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 循环动画 | linear | 呼吸灯、粒子飘动 |

**关键特征：几乎不使用弹簧/弹性动画。** 一切运动"有目的、有节制、有重量"。

### 7.4 时间参数

| 类别 | 时长 |
|------|------|
| 微交互（按钮/hover） | 100-150ms |
| 小型转场（标签/下拉） | 200-300ms |
| 中型转场（面板/页面） | 300-400ms |
| 大型转场（全屏/寻访） | 500-2000ms+ |
| 循环动画（呼吸灯/粒子） | 2000-4000ms/周期 |

### 7.5 呼吸动画（Respire）

方舟 UI 中反复出现的设计模式——指示活跃/等待状态：
```css
@keyframes respire {
  0%   { border-bottom: 1px solid rgb(var(--highlight-primary-color), 0.3); }
  100% { border-bottom: 1px solid rgb(var(--highlight-primary-color), 1); }
}
```

### 7.6 粒子效果

- **主界面**：缓慢飘动的微小光点/尘埃粒子
- **源石相关界面**：蓝紫色结晶粒子缓慢上升
- **按钮确认**：白/黄色粒子从中心向外扩散
- **升级完成**：金色粒子爆发 + 光晕扩散

### 7.7 寻访（Gacha）动画

稀有度视觉区分：
- 3★：灰白微弱光芒，无粒子，动画简短
- 4★：蓝白光芒，少量粒子
- 5★：金黄光芒，明显粒子爆发，动画更长
- 6★：彩虹/橙金强烈光芒，大量粒子，画面震动（screen shake），"天空变色"效果

## 九、音效设计

由 Monster Siren Records（鹰角旗下音乐厂牌）制作。

### 特征：

- **金属质感**：按钮点击模拟机械开关"咔嗒"
- **电子合成**：转场带轻微电子嗡鸣
- **低频底噪**：界面背景极低音量环境音，增加"终端"沉浸感
- **克制短促**：所有 UI 音效 50-200ms

### 音画同步：

| 交互 | 音效 |
|------|------|
| 按钮按下 | 触摸瞬间触发，与视觉缩小同步 |
| 面板滑入 | 短促"嗖"声 |
| 确认操作 | 上升音调 |
| 取消/返回 | 下降音调 |
| 错误/警告 | 不和谐电子音 |
| 6★寻访揭示 | 标志性震撼音效（玩家听到即知结果） |

BGM 切换使用 crossfade 1-2 秒。

4. 色彩纯功能性使用
5. 核心 UI 框架从 2019 至今高度稳定

## 十一、关键设计规则速查

1. **绝对直角**：几乎所有元素 border-radius: 0
2. **无投影**：不用 box-shadow，靠色块对比区分层级
3. **半透明叠加**：opacity 0.7~0.9 是核心手法
4. **橙红标记线**：`#FF5E19` 短横线是品牌标识
5. **宋体标题**：功能名称用衬线体增加仪式感
6. **图标半透明**：opacity 0.5 + invert 滤镜，装饰而非主导
7. **色块即按钮**：不依赖边框/阴影
8. **信息克制**：每面板只展示最核心 1~2 个信息点
9. **透视倾斜**：主界面左右菜单 3D perspective
10. **暗色主导**：亮色面板作为信息载体浮于暗底之上
11. **无弹簧动画**：运动干脆利落，无多余振荡
12. **斜线/对角线**：转场、分割、装饰大量使用倾斜元素
