# Evidence Coverage Review

## Coverage

- Affect/appraisal/personality claims are tied to foundational citations already present in `docs/theory.md`.
- Memory and lifelike claims are tied to foundational memory literature and repository implementation.
- Engineering validation uses real remote benchmark summaries and existing lifecycle aggregation.
- Synthetic/mock paper data under `output/paper/**` is excluded from empirical claims.

## Gaps And Controls

- The lifecycle cross-model fit has only one sample per time scale and must be labeled as explanatory, not confirmatory.
- Remote latency includes WebUI, AstrBot, provider, network and queueing, so figures must avoid presenting it as pure plugin runtime cost.
- The theory document should state that psychological screening is non-diagnostic.
