# Sylanne Computation Theory

Two novel formal frameworks for relational AI computation.

## Structure

```
theory/
├── scar_algebra/       # Self-Modifying Operator Algebras
│   ├── axioms.md       # Formal axiom system
│   ├── theorems.md     # Statements + proofs
│   └── impl/           # Reference implementation
├── void_calculus/      # Absence as Primitive Computation
│   ├── axioms.md       # Formal semantics
│   ├── theorems.md     # Statements + proofs
│   └── impl/           # Reference implementation
└── integration.md      # How both theories unify into the computation spine
```

## Goals

1. **Scar Algebra**: Prove expressiveness separation from fixed-operator dynamical systems
2. **Void Calculus**: Prove irreducibility to belief revision / probabilistic logic
3. **Integration**: Replace SSM (Layer 3) and TDA (Layer 4) in the existing spine
