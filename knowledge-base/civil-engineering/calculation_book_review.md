# 计算书审查清单

## 总体链条

按“设计条件 -> 荷载 -> 组合 -> 内力 -> 配筋/承载力 -> 构造 -> 基础 -> 图纸表达”检查。不要只看最后配筋结果。

## 高风险问题

- 设防烈度、场地类别、设计地震分组、抗震等级前后不一致。
- 楼面活载、屋面活载、楼梯活载、风荷载参数无来源。
- 荷载单位混用，kN/m、kN/m2、N/mm2 未转换。
- 梁柱截面、混凝土强度、钢筋等级与图纸不一致。
- 只贴软件输出，无手算说明、参数说明或结果判读。
- 构件承载力满足但构造措施遗漏，如箍筋加密、锚固、搭接、最小配筋率。
- 基础计算缺少地基承载力修正、偏心验算或沉降说明。

## 审查顺序

1. 工程概况：建筑尺寸、层高、结构体系、材料等级。
2. 规范依据：标准号和版本是否完整。
3. 荷载取值：恒载分层统计，活载按房间功能，风雪按地区参数。
4. 地震作用：设防烈度、场地类别、特征周期、影响系数。
5. 内力分析：手算模型假定、软件模型假定和边界条件。
6. 梁板柱墙：截面、内力、配筋、裂缝/挠度、构造措施。
7. 楼梯、雨篷、节点：专项构件不能缺失。
8. 基础：基础形式、承载力、冲切、剪切、配筋。
9. 汇总表：计算书最终构件表应与施工图一致。

## 输出模板

```text
问题等级：高/中/低
位置：计算书第 X 章 / 表 X / 图 X
问题：说明具体不一致或缺漏。
依据：任务书、标准索引或文献依据。
影响：对承载力、构造、图纸表达或答辩的影响。
建议：给出可直接改写的句子或补算项。
```
