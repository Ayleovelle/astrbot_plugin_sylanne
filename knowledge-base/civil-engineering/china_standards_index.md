# 中国建筑与土木工程常用标准索引

本索引只提供标准号、名称、适用方向和官方检索入口，不再分发标准全文。使用前必须核对学校要求、项目所在地地方标准和现行版本。

官方检索入口：

- 全国标准信息公共服务平台：https://std.samr.gov.cn/
- 住房和城乡建设部标准定额司/公开信息：https://www.mohurd.gov.cn/
- 国家工程建设标准化信息网：http://www.ccsn.gov.cn/

## 使用原则

1. 先查强制性通用规范，再查专项设计规范和地方标准。
2. 计算书引用标准时写清标准号、名称、版本年份和条文主题。
3. 标准版本不确定时，只能写“需按现行版本核对”，不要编造条文号。
4. 图集、教材、学校优秀毕业设计不等于规范依据，只能作为表达和学习参考。
